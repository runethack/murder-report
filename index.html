# MURDER Report MURDER Report — это Python-инструмент для первичного OSINT-анализа открытых данных: - username - домены - email - номера телефонов - IP-адреса - изображения (EXIF/GPS) Он предназначен для образовательных целей, тестовых сред и анализа систем, на которые у вас есть явное разрешение. ## Что умеет - Проверка username на популярных платформах - Анализ домена: DNS, WHOIS, RDAP, субдомены, path brute - Анализ email: синтаксис, MX, disposable, Gravatar, утечки - Анализ телефона: нормализация, страна, оператор, WhatsApp, отзывы - Анализ IP: geo, Whois, reverse DNS - Анализ изображений: EXIF, GPS, ссылки на обратный поиск - Генерация возможных email по username - Генерация JSON/HTML-отчётов ## Установка ```bash git clone https://github.com/runethack/murder-report.git cd murder-report python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt ``` ## Запуск ### Интерактивный режим ```bash python3 main.py ``` ### Командная строка ```bash # username python3 main.py -u someuser # домен python3 main.py -d example.com # email python3 main.py -e user@example.com # телефона python3 main.py -p +79001234567 # IP python3 main.py -i 8.8.8.8 # изображение python3 main.py --image /path/to/file.jpg # генерация email из username python3 main.py --emails someuser python3 main.py --emails someuser --emails-domain gmail.com,proton.me ``` ## Агрессивная проверка Некоторые режимы создают много HTTP-запросов и могут быть заблокированы: - brute-force путей - crawl robots/sitemap - authbrute - проверка множества сайтов с отзывами - nmap / subfinder / whatweb / wafw00f / httpx / nuclei Используйте их только на системах, которыми вы владеете, или с явного разрешения владельца. ## Отчёты Каждый запуск сохраняет JSON и HTML-файл, например: ```bash python3 main.py -d example.com -o report ``` Создаст: - report.json - report.html ## Лицензия MIT License. См. файл `LICENSE`. ## Важно Используйте проект только для: - собственных систем - тестовых сред - проектов, на которые есть разрешение - образовательных задач Использовать в незаконных или несанкционированных целях запрещено. ## Источник данных для телефона В веб-версии номера используется источник: ```javascript const API_URL = "https://num.voxlink.ru/get/v2/?num="; ``` или, в Python-стиле: ```python url = f"https://num.voxlink.ru/get/v2/?num={num}" ```
